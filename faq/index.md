## 一、基础概念篇：网络代理、机场与线路拓扑解密

### 1. 什么是“机场”？为什么叫这个名字？
“机场”是中文互联网圈对“商业化科学上网代理服务提供商”的通俗戏称。这一名词起源于 2012 年由 clowwindy 开发的开源代理工具 **Shadowsocks**。因为 Shadowsocks 的官方 Logo 是一只纸飞机（Paper Airplane），客户端将配置好的代理节点称为“节点”，用户把购买代理服务的平台比喻为供纸飞机起降的“机场”。随着生态的发展，如今“机场”已泛指支持 Shadowsocks、V2Ray、Xray、Sing-box、Trojan 等多协议的商业代理集群平台。

### 2. 机场与传统 VPN（如 ExpressVPN / NordVPN）有什么本质不同？
很多初学者经常将机场混同为 VPN，二者在底层原理与设计初衷上存在本质差异：

| 比较维度 | 商业机场 (Proxy Cluster) | 传统商业 VPN (如 Nord / Express) |
|:---|:---|:---|
| **核心协议** | VLESS / SS / Trojan / Hysteria 2 | OpenVPN / WireGuard / IPsec / IKEv2 |
| **设计目标** | **流量混淆伪装**，穿透深度包检测（GFW） | **数据通道强加密**，保障局域网安全与防窃听 |
| **GFW 识别难度** | 极难识别（流量被伪装为合法 HTTPS 浏览） | 极其明显（固定握手特征，公网存活不足数小时） |
| **国内入口机制** | 采用国内 BGP 多线入口或内网物理专线 | 国内通常无入口，客户端直连境外机房，易被 QoS |
| **分流与规则** | 支持精准的基于域名/IP的分流规则（分流国内/国外） | 通常为全局虚拟网卡接管，国内访问速度极慢 |
| **晚高峰表现** | 专线架构下可实现晚高峰零丢包 | 晚高峰公网丢包通常高达 30%~50% |

### 3. IEPL 物理专线、BGP 智能中转与普通公网直连的区别
理解线路拓扑是挑选合适服务商的基础：

```
【物理专线架构 (IEPL / IPLC)】:
用户终端 ──(低延迟内网)──> 国内BGP入口 ──[物理海底/陆地光纤专线直达]──> 境外POP落地 ──> 目标网站
特性：全程不经过公网 GFW 审查，丢包率为 0%，晚高峰极度稳定，成本最高。

【BGP 智能中转架构】:
用户终端 ──(多线BGP接入)──> 国内中转服务器 ──(公网加密隧道隧道转发)──> 境外落地 ──> 目标网站
特性：国内入口体验佳，中途走公网，遇到国际骨干拥塞时可能有偶发跳 ping。

【普通公网直连架构】:
用户终端 ──────────────────────(直接跨越公网 GFW 审查)──────────────────────> 境外VPS落地 ──> 目标网站
特性：成本极低，但在晚高峰遭受严格 QoS 限速与高丢包，极易被封 IP。
```

## 二、传输协议篇：SS / VMess / VLESS / Trojan / Hysteria 2 全景横评

不同的代理协议在性能开销、握手延迟与抗封锁能力上存在显著差异：

### 1. 经典协议：Shadowsocks (SS)
- **特点**：基于对称流加密（AEAD），CPU 运算开销极小，并发吞吐性能极佳。
- **现状**：由于握手包无外部伪装，直接暴露在公网时极易被 GFW 的深度神经网络识别；目前 **仅建议在 IEPL/IPLC 物理内网专线内部使用**。专线内使用 SS 能够获得最低的设备耗电量与最高的数据吞吐。

### 2. 现代混淆标杆：VLESS + XTLS-Reality
- **技术突破**：由 Xray 团队提出。Reality 彻底抛弃了传统的自签名或免费 Let's Encrypt 证书伪装方案，而是直接借用互联网上真实的外部大厂证书（如 Apple、Microsoft、Amazon 的真实 TLS 1.3 证书）。
- **优势**：中间审查者在握手阶段看到的完全是目标大厂的真实证书链，彻底消除了证书特征指纹，是目前公网抗封锁能力最强的现代协议。推荐主力机场如 **[光速云](/airports/guangsu)** 优先选用。

### 3. 基于 UDP/QUIC 的暴力冲锋协议：Hysteria 2 & TUIC v5
- **特点**：基于标准化 QUIC 协议深度改造，内置自研的 Brutal 拥塞控制算法。
- **适用场景**：在恶劣高丢包网络（如移动宽带或偏远地区）下，传统 TCP 遇到丢包会触发退避算法大幅降速，而 Hysteria 2 能在高达 30% 丢包的网络环境中依然强行拉满带宽。
- **缺点**：部分省份运营商（尤其是晚高峰期）对非标准 UDP 流量实行了严重的 QoS 劣化甚至限速阻断。

## 三、客户端实战排障篇：全平台高频报错解决 SOP

当遇到连接异常时，请对照以下 SOP 标准排查流程：

### 1. 报错：`Handshake timeout` 或 `i/o timeout`
- **原因分析**：客户端与节点服务器之间的网络通道未建立。
- **排查步骤**：
  1. 登录机场官网用户中心，确认订阅是否已过期或流量已耗尽；
  2. 在客户端点击“更新订阅”，确认是否由于机房维护割接导致节点域名/端口变更；
  3. 切换为同机场的其他国家/地区节点，排查是否为单点机器临时故障。

### 2. 状态显示已连接，但浏览器打不开任何网页
这是最困扰新手的高频问题，通常由以下三个原因引起：
- **原因一：系统代理环境变量未成功写入**。部分浏览器（如 Chrome）依赖系统的代理设置。若第三方杀毒软件或清理工具篡改了注册表，代理设置将失效。解决方法：在 Windows 设置中搜索“代理”，确认“使用代理服务器”开关已开启，且端口与 Clash 监听端口（默认 7890）一致。
- **原因二：系统时间误差超过 90 秒**。TLS 加密握手对时钟精度有极严格要求。若本地电脑主板电池老化或系统时间偏差超过 90 秒，TLS 握手会直接判定证书无效并静默断开。解决方法：右键任务栏时间 ->“调整日期/时间”-> 点击“立即同步”。
- **原因三：DNS 污染与解析死锁**。在客户端设置中将 DNS 模式由系统默认切换为 Fake-IP 或 启用内置加密 DNS（如 1.1.1.1、8.8.8.8）。

### 3. TUN 虚拟网卡模式与系统代理模式如何选择？
- **系统代理（System Proxy）**：轻量级，仅代理遵循操作系统代理 API 的软件（如浏览器、Telegram 等）；无法代理命令行终端、未配置代理的代码环境或大部分网络游戏。
- **TUN 虚拟网卡模式（Tun Mode）**：重量级，在系统内核级别创建一张虚拟网卡，接管所有 TCP/UDP 流量，实现真正的全局接管。适合需要加速 Steam 跨服联机、命令行 Git 克隆或 Docker 镜像拉取的场景。

## 四、流媒体与 AI 解锁篇：原生 IP、DNS 泄露与风控破解

### 1. 为什么同一个节点能看 YouTube，却看不了 Netflix 原生剧？
- YouTube 仅校验访问者是否位于可服务的国家/地区，对机房 IP（Datacenter IP）几乎不做限制；
- Netflix 与 Disney+ 拥有全球最严苛的版权保护数据库。它们会定期比对 MaxMind 等商业 IP 库，一旦检测到该 IP 属于机房托管商（如 Amazon AWS、Google Cloud、DigitalOcean），就会限制用户观看拥有独家地区版权的内容，仅允许观看 Netflix 自制剧（Netflix Originals）；
- **解决方案**：必须选用具备 **原生双 ISP 住宅出口** 的高端专线节点（如 **[光速云](/airports/guangsu)**）。

### 2. ChatGPT 提示 `Access Denied` (Error 1020) 彻底解决流程
OpenAI 对接口请求施加了严密的 Cloudflare Turnstile 与行为指纹检测：
1. **清理本地指纹**：清除浏览器所有与 `openai.com` 相关的 Cookies 与 LocalStorage，或开启无痕模式；
2. **选择纯净出口**：切换至机场专门标注为 `AI`、`ChatGPT` 或 `住宅IP` 的专属节点；
3. **禁用网页翻译扩展**：部分浏览器自带的全页自动翻译插件会高频请求后端 API，极易被 OpenAI 误判为自动化抓取脚本触发安全防御；
4. **绑定精准分流规则**：在规则配置中确保 `openai.com`、`chatgpt.com`、`auth0.openai.com` 全部强制走 PROXY 纯净节点。

## 五、资费购买与资金安全避坑篇：月付、倍率与维权指南

### 1. 为什么我们始终强调“能月付绝不年付”？
代理行业缺乏合规金融监管与托管机制。根据近五年统计，市场上超过 70% 的中小型机场运营寿命不足 18 个月。商家通过“三年付超低折扣”回笼大量资金后，一旦遭遇机房拔线或严打，极易选择携款关站。**坚持月付，即使遭遇跑路，单次损失也仅控制在一杯咖啡的金额之内**，拥有绝对的止损主动权。

### 2. 识别“倍率刺客”：警惕 0.1x 噱头与 5x 陷阱
很多用户看到某些机场宣称“10 元 1000G 流量”，购买后使用两三天就收到流量耗尽通知。这往往是因为商家采用了“倍率杀熟”手段：
- 宣称的 1000G 是按 **0.1 倍率** 节点计算的理论值；
- 而用户实际必须使用的晚高峰主力香港、日本线路，倍率被暗中设为 **3.0x 甚至 5.0x**；
- 当你在 5.0x 节点上下载 1GB 视频时，系统后台会扣除 **5GB 流量**，实际可用流量缩水 80%！
- **建议**：在购买前务必查阅商家的节点列表，核对主力节点的真实倍率。

## 七、20 个超高频痛点 FAQ 精准解答全集

### Q1: 什么是直连？什么是中转？什么是专线？
**答**：直连是客户端直接连接境外机房，受公网拥塞和 GFW 审查直接影响；中转是客户端先连国内机房，再由国内机房公网加密隧道发往境外；专线是国内机房与境外机房之间租用了物理光纤内网，完全不走公网 GFW，稳定性最高。

### Q2: 为什么我的订阅链接更新失败？
**答**：通常是因为机场的订阅下发域名被 GFW 污染阻断。请尝试在客户端关闭代理后直连更新，或在浏览器中打开机场官网，进入后台复制最新的“备用防污染订阅链接”或订阅转换链接。

### Q3: 为什么连接节点后微信发不出消息或朋友圈打不开？
**答**：这是因为客户端开启了全局代理（Global Mode），导致国内社交软件流量也强行经由境外节点绕行。请务必将客户端路由模式切换为 **“规则模式”（Rule Mode）**，让微信、QQ、网易云等国内直连应用直接走本地网络。

### Q4: 节点名称中的 BGP 是什么意思？
**答**：BGP（Border Gateway Protocol，边界网关协议）。具备 BGP 入口的机场，能够动态感知电信、联通、移动的骨干网络状况，将不同运营商的用户智能调度到最优的网络入口，避免跨运营商互联结算导致的丢包。

### Q5: 机场节点能不能用来打 LOL、CSGO 或 Valorant 跨服联机？
**答**：普通机场节点通常不建议打竞技类网络游戏。虽然专线机场延迟很低，但竞技网游高度依赖 Full-cone NAT 与稳定的 UDP 低抖动；若服务商未对 UDP 做专属路由调优，可能出现丢包卡顿。建议游戏玩家选用专业游戏加速器或标有“游戏专线/UDP特供”的专属节点。

### Q6: 为什么有时看同一个视频，手机很流畅电脑却很卡？
**答**：排查电脑端是否存在后台其他软件在占用加密解密算力或网速。此外，电脑端屏幕分辨率高（通常默认加载 1440P 或 4K），对持续带宽吞吐要求高出数倍；手机端屏幕尺寸小，通常默认加载 1080P，带宽压力明显更小。

### Q7: 机场主能看到我的上网浏览记录或账号密码吗？
**答**：只要您访问的网站是正规的 HTTPS 加密网站（现代互联网 98% 以上网站均是 HTTPS），数据在传输前已在您的本地浏览器中进行了强加密，机场主在服务器端只能看到您连接的目标域名或 IP 地址，**绝不可能看到您的明文密码、聊天记录或资金详情**。但请务必避免在未加密的 HTTP 明文网页中输入敏感凭证。

### Q8: 什么是 Clash 的 Fake-IP 模式？它有什么好处？
**答**：在传统 Redir-Host 模式下，客户端每次访问域名都需要先通过本地向 DNS 服务器发起解析获取真实 IP，极易遭受本地 DNS 污染；而在 Fake-IP 模式下，Clash 直接返回一个虚拟的内部 IP（如 198.18.0.x），真正的域名解析交由境外远端节点代为完成，不仅彻底杜绝了 DNS 污染，还将首次打开网页的延迟缩减了近 50%。

### Q9: 为什么有的机场不支持支付宝/微信直接扫码，而是跳第三方网页？
**答**：国内合规支付公司禁止向跨境代理服务提供支付通道。因此，商业机场普遍接入海外第三方聚合支付网关或多级跳转商户号，以规避支付通道风控。

### Q10: 什么是“永久不过期套餐”？它靠谱吗？
**答**：永久不过期套餐（如 [光速云斯诺克 147 套餐](/airports/guangsu)）是一种一次性按量计费包，不设月度清零机制，用完即止。它非常适合低频查资料或备用用户。只要服务商属于运营多年、信誉卓越的老牌大厂，这种套餐就是极具性价比的省钱利器。

### Q11: 为什么有时候节点延迟很低，但测速速度却很慢？
**答**：客户端显示的“Ping 延迟”仅代表本地到国内入口服务器（或单次 TCP 握手）的往返时间（RTT），并不代表该节点在国际出口上的总可用带宽吞吐量。若该节点的出口服务器被大量用户同时跑满，或服务商未购买充足的国际回国海缆带宽，就会出现“低延迟但低吞吐”的拥塞假象。

### Q12: 什么是 DNS 泄露？它会有什么安全风险？
**答**：DNS 泄露是指当您通过代理访问境外网站时，浏览器或客户端未将 DNS 解析请求发送至境外的加密 DNS 服务器，而是依然向本地运营商（如中国电信/中国移动本地 DNS 递归服务器）发送明文解析请求。这会导致本地运营商完全记录下您访问了哪些境外域名。解决方法是在 Clash/Sing-box 中启用 Fake-IP 模式并配置 DoH（DNS-over-HTTPS）或 DoT（DNS-over-TLS）远程加密解析。

### Q13: 在 macOS 上开启代理后，为什么控制台终端命令行还是不走代理？
**答**：macOS 的系统代理设置仅对遵循系统代理环境变量的 GUI 应用程序有效，终端命令行（如 `curl`、`git`、`npm`、`brew`）默认直接发起直连网络请求。解决方法是在终端配置文件（`~/.zshrc`）中添加以下别名函数：
```bash
# 终端一键开启代理
alias setproxy="export http_proxy=http://127.0.0.1:7890; export https_proxy=http://127.0.0.1:7890; echo 'Proxy on'"
alias unsetproxy="unset http_proxy; unset https_proxy; echo 'Proxy off'"
```
或者直接在客户端中开启全局 TUN 虚拟网卡模式接管系统内核所有流量。

### Q14: 什么是路由规则中的 DIRECT、PROXY 与 REJECT？
**答**：这是现代分流客户端的三大基本动作：
- **DIRECT（直连）**：不经过代理，本地直接与目标服务器建立连接，用于中国大陆网站及局域网流量；
- **PROXY（代理）**：将数据包打包加密后发送给选中的代理节点，由境外节点代为访问；
- **REJECT（阻断/拒绝）**：直接丢弃该数据包，通常用于过滤全网广告、跟踪器或恶意挖矿域名。

### Q15: 多个设备共用一个机场账号，会被封号或限制速度吗？
**答**：取决于具体服务商的“设备并发限制策略”。部分平价中转机场严格限制 2~3 个同时连接 IP，一旦超出限制会自动踢出已连接设备；而高端旗舰机场（如 [暮光加速](/airports/muguang)）通常支持不限设备数并发，适合外贸团队或家庭多成员共同使用。在购买前请务必确认套餐的设备数条款。
