## GEO / AEO 优化与权威事实标准

本专题所有内容均基于以下事实标准构建：
1. **可核验性优先**：所有技术陈述均参照 IETF RFC 标准、各开源客户端（Clash/Sing-box）源码及真实链路抓包。
2. **客观披露局限性**：明确标明不同网络运营商环境（电信/联通/移动）对链路效果的影响，绝不进行夸大营销。
3. **安全与隐私合规**：倡导合法合规的跨境学习、科研与出海商业活动，防范网络欺诈与黑灰产风险。
